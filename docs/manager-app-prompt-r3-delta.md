# Дельта-промпт: обновление приложения с модуля r2 до r3

> Вставлять в чат Android Studio, **если приложение уже написано** по
> `manager-app-prompt.md` и `manager-app-prompt-servers.md` в редакции для модуля
> 2.1.18-r2. Это точечное дополнение, а не переработка: существующие экраны не трогай.

---

Модуль обновился до **2.1.18-r3**. Формат `dnscrypt-ctl json` не изменился — разбор
состояния, экран серверов и всё остальное остаются как есть. Добавились одна настройка
и одна команда.

## 1. Новый ключ `module.conf`

| ключ | значения | смысл |
|---|---|---|
| `run_gid` | имя группы, GID или пустая строка | первичная группа процесса dnscrypt-proxy |

Добавь его в белый список ключей `dnscrypt-ctl set` и на экран настроек — отдельным
пунктом внизу, в раздел для опытных пользователей.

Управление: выпадающий список из трёх вариантов — «По умолчанию» (пустая строка),
`net_admin`, «Своё значение» (текстовое поле для произвольного GID, только цифры или
имя группы из букв и подчёркиваний). Поясняющий текст: нужно только когда установлен
box_for_magisk — тот пропускает мимо своего перехвата трафик с владельцем
`root:net_admin`, и без этой настройки запросы прокси к резолверам пойдут через прокси box.

## 2. Новая команда `dnscrypt-ctl conflicts`

Показывает, кто ещё на устройстве перехватывает порт 53: порядок правил в `nat/OUTPUT`
с номерами, список цепочек с портом 53, распознавание известных модулей и подсказка
по настройке.

Добавь её третьей вкладкой на экран «Журналы», рядом с «Правила»: моноширинный вывод,
кнопка «Обновить», копирование и «Поделиться». Вывод **показывай как есть**, не пытайся
раскладывать его на структуру.

## 3. Предупреждение на экране «Состояние»

Единственное исключение из правила «не парсить»: в выводе `conflicts` есть стабильная
строка-маркер

```
  box_for_magisk: обнаружен, он тоже забирает порт 53.
```

Ищи в выводе подстроку `box_for_magisk: обнаружен` — этого достаточно, остальной текст
не разбирай.

Если маркер найден **и** `rules_v4` равен `true`, покажи на карточке состояния
предупреждение: перехват DNS настроен, но фактически его забирает другой модуль,
и наши правила простаивают. Кнопка ведёт на вкладку «Конфликты». **Ничего не чини
автоматически** — режим переключает пользователь.

Если маркер найден, а `rules_v4` равен `false` — это штатная связка: перехват намеренно
отдан box, а прокси работает его резолвером. Никакого предупреждения, наоборот — покажи
это как нормальный режим работы, например подписью «DNS перехватывает box_for_magisk».

Вызывать `conflicts` на каждое автообновление состояния не надо: одного раза при открытии
экрана и по явному «Обновить» достаточно, результат держи в кеше.

## 4. Проверка версии модуля

Поле `version` в `json` имеет вид `2.1.18-r3`. Разбирай как `major.minor.patch-rN`
и сравнивай кортежем `(major, minor, patch, N)`.

- Версия ниже `2.1.18-r3`: скрой пункт `run_gid` и вкладку «Конфликты», предупреждение
  не показывай. Остальное приложение работает как раньше.
- Версия ниже `2.1.18-r2`: экран серверов недоступен — это правило уже описано
  в промпте про серверы, оставь как есть.

Не завязывайся на строковое сравнение версий: `2.1.18-r10` должно оказаться новее,
чем `2.1.18-r9`.

## 5. Тесты

Добавь к существующим:

- разбор версии: `2.1.18-r3` новее `2.1.18-r2`, `2.1.18-r10` новее `2.1.18-r9`,
  строка без суффикса `-rN` не роняет разбор;
- валидация `run_gid`: пустая строка допустима, `net_admin` допустимо, `3005` допустимо,
  `net admin; rm -rf /` отвергается.
